# ПР2. Ответы на контрольные вопросы

1. Для денежных расчётов используют `decimal`, потому что он точнее представляет десятичные дроби. У `double` может появиться небольшая погрешность, например при сложении 0.1 и 0.2.

2. Если значение выходит за диапазон целочисленного типа, происходит переполнение. Например, в примере с `byte` после 255 получается 0.

3. `var` не делает переменную динамической: компилятор определяет её тип один раз по начальному значению. Например, `var age = 20;` создаёт переменную типа `int`.

4. `Console.ReadLine()` всегда возвращает текст типа `string`, даже если пользователь ввёл цифры.

5. `int.Parse` выдаёт ошибку при некорректном вводе. `int.TryParse` не завершает программу с такой ошибкой, а возвращает `false`.

6. `false` означает, что преобразовать текст в число не удалось. Для переменной `int`, переданной через `out`, в этом случае будет значение 0.

7. `TryParse` удобно использовать для данных, которые вводит пользователь: он может случайно написать буквы вместо числа. `TryParse` позволяет обнаружить неправильный ввод без аварийного завершения программы.
